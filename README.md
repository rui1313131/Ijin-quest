# Ijin-quest

## 目的
偉人の名称と功績等をクイズ形式で楽しく、簡単に学習するため

## 概要
歴史上の偉人について学べるクイズサイトを作成しました。
問題に回答すると、正解・不正解のページが表示されます。

## 使用技術
HTML/CSS
JavaScript

## 使用方法
### 1.こちらのリンクをクリック:https://rui1313131.github.io/Ijin-quest/index.html
### 2.「問題」の下に記載されている文章を読み、どの人物の説明文であるかを予想し、適切な人物名を3つの選択肢から選びクリックをする。
### 3.「この選択肢で正解」というボタンを押し、正解か不正解かを確認する。
### 4.もし前の問題や次の問題を解答したい場合は下端にある「前の問題へ戻る」か「次の問題へ進む」で適したボタンをクリックする。

## 工夫した点
### ・選択肢をクリックする際に色の変化を与えることでクリックできているかという不安を減らしたこと。
### ・文字の色や大きさを変えることで読みやすい見た目にしたこと。
